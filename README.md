🏠 House Price Prediction

A machine learning-based web application that predicts the estimated price of a house based on important property features such as built-up area, number of bedrooms, bathrooms, property age, parking spaces, and location quality.

The project uses Random Forest Regression for price prediction and Streamlit to provide an interactive and user-friendly interface. It also includes market insights and model performance information to make the prediction system easier to understand.

Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Plotly

Machine Learning Algorithm

- Random Forest Regression

Features

- 🏠 House price prediction
- 📐 Property area input
- 🛏️ Bedroom and bathroom selection
- 🚗 Parking information
- 📍 Location quality
- 📊 Market insights and visualizations
- 🤖 Model performance metrics
- 💻 Interactive Streamlit interface
